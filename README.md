# Amor Zodiacal

Wallpaper animado para Samsung S24 (Wallpaper Engine) a partir de la ilustración original
`Wallpaper001.jpeg`: Géminis y Capricornio, corazones y estrellas.

## Versiones
- **v1**: loop de 10 s a 30 fps. Las estrellas titilan, los corazones laten, los signos respiran,
  pasa una ola de luz y flotan partículas doradas. → `releases/v1/`

## Cómo regenerar
```bash
python -m venv venv && venv/Scripts/pip install -r requirements.txt
```
Ver los scripts en `src/`.
